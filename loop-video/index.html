Two kinds of loop, one click each

Repeat writes your clip back-to-back N times using stream copy — the compressed data is duplicated, not re-encoded, so a 2× to 10× loop of even a large file finishes in seconds with zero quality loss. Boomerang renders the clip forward then immediately backward, so the last frame flows back into the first — the loop point disappears entirely. Boomerang involves a reverse render, so it's best on short clips (the same memory note as our reverse tool applies).

Where loops work

  • Social posts — boomerang a 2-second action for that hypnotic, seamless replay.
  • Presentations & signage — repeat a product clip 10× so it survives a long slide.
  • Backgrounds — loop ambient footage for streams and waiting screens.
  • GIF prep — loop first, then feed the result to Video to GIF.

Loop length math

The new duration is shown live: a 4-second clip repeated 5× is 20 seconds; the same clip boomeranged at 2× is 16 seconds (forward+reverse, twice). Audio is kept in repeat mode and reversed along with the picture in boomerang mode.

FAQ

What is boomerang mode?

Forward then backward, ending where it began — the loop point is invisible. Instagram's effect, for any video, free.

Why is plain looping so fast?

Stream copy: the compressed video is written N times without re-encoding. Zero quality loss, seconds even for big files.

How many times can I loop?

2× to 10×. Boomerang doubles the clip and can also repeat.

Is my video uploaded to loop it?

No — everything runs in your browser. No upload, no watermark.
